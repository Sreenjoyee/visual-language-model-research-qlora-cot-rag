Chain-of-Thought Prompt Structure: Dialogue Template and Supervised Reasoning Format
The conversation follows the LLaMA-3 chat template. A fixed system turn defines the clinical role; the user turn embeds visual tokens alongside FAISS evidence; the supervised assistant turn trains four-step reasoning with a format kept identical at inference to prevent prompt drift.

If evidence is insufficient, say so rather than speculate."

1 System Prompt
Contains no disease names or hints, so the model cannot infer the expected answer from the question framing. The identical text is used at training and inference, preventing any diagnostic label from leaking into the question-side loss.

2 <IMAGE> Token Splice
pipeline.py replaces this placeholder with 8 Perceiver output vectors as inputs_embeds, bypassing the text tokeniser. The model attends to visual features at exactly this sequence position.
3 FAISS Retrieved Evidence
Five passages are fetched by querying FAISS with the model's own image-caption output, so retrieval is driven by observed findings rather than a generic query. The numbered format lets the model cite specific passages in EVIDENCE_USED. In 20% of training examples, passage [5] is replaced with an adversarial snippet to improve robustness against misleading retrieved evidence.
4 Structured Output Constraint
The format is enforced token-by-token via cross-entropy on build_classification_target() outputs and kept identical at inference (SRS §12). Any departure degrades label parsing. EVIDENCE_USED logs which passages were cited, enabling post-hoc measurement of susceptibility to misleading retrieved evidence in Experiment 4B.

Fig. 4. Dialogue template and chain-of-thought supervised training format. (System turn) A fixed, bias-free system message establishes the radiology assistant role without embedding any disease names or diagnostic cues. The same text is used verbatim during Stage 2 training and at inference. (User turn) Three components are assembled at runtime: (i) a visual context block where the IMAGE placeholder is replaced by 8 Perceiver Resampler output vectors injected as inputs_embeds, bypassing the text tokeniser; (ii) five FAISS-retrieved clinical passages formatted by format_retrieved_evidence(), with passage [5] replaced adversarially in 20% of training examples; and (iii) a structured output format instruction specifying the four-field response schema. (Assistant turn) Training targets from build_classification_target() cycle through 13 diverse reasoning templates indexed by step count to prevent template memorisation. Step 3 substitutes real MIMIC-CXR report text when available. Loss is computed on assistant turn tokens only; all prompt positions carry labels = −100.
